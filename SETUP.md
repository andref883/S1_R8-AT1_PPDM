# Passo a passo

1. Criar o projeto:
   npx create-expo-app@latest VideoFinder --template blank
   cd VideoFinder

2. Instalar dependências de navegação:
   npx expo install @react-navigation/native @react-navigation/native-stack react-native-screens react-native-safe-area-context

3. Copiar para dentro do projeto (substituindo o App.js):
   App.js  e a pasta  src/

4. Rodar:
   npx expo start     (tecla "a" abre o emulador Android)

5. GitHub:
   git init
   git add .
   git commit -m "Atividade prática: app mobile com API"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/NOME-DA-ATIVIDADE.git
   git push -u origin main
